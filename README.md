# ASIR-LAB
Laboratorio personal de Administración de Sistemas, Redes, Base de Datos y Tecnologías vistas durante el curso de Adminsitración de Sistemas Informáticos en Red (ASIR).

## Sobre este proyecto
Este repositorio documenta la construcción de un laboratorio personal desarrollado durante mi formación en Administración de Sistemas Informáticos en Red (ASIR).

El objetivo es diseñar, implementar y documentar una infraestructura tecnológica basada en entornos reales de empresa, aplicando de forma práctica los conocimientos adquiridos en sistemas, redes, virtualización, administración de servidores, bases de datos y ciberseguridad.

Cada proyecto refleja el proceso de aprendizaje, las decisiones técnicas tomadas, las incidencias encontradas y las soluciones implementadas, creando un portfolio técnico que demuestra la evolución de mis competencias profesionales en el ámbito de la administración de sistemas y la ciberseguridad.
