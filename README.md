# ASIR-LAB
Laboratorio personal de Administración de Sistemas, Redes y Ciberseguridad

## Sobre este proyecto

Este repositorio documenta los laboratorios y proyectos realizados durante mi fomración en Administración de Sistemas Informáticos en Red ASIR.
El objetivo es construir una infraestructura empresarial virtual completa utilizando tecnologías  reales empleadas en entornos corporativos.

## Tecnologías
- Virtual Box
- VM Windows Server 2022
- VM Windows 11 Pro
- VM Ubuntu Server/Desktop
- Active Directory
- DNS
- DHCP
- GPO
- Samba
- Kerberos
- Winbind
- Redes
- VLAN
- Routing
- MySQL

## Proyectos
01 - Virtualización
02 - Redes Virtuales
03 - Grupos de Trabajo Locales
04 - Active Directory
05 - DHCP
06 - Compartición NTFS 
07 - GPO
08 - Samba y Kerberos en VM Ubuntu


## Objetivo Profesional
Desarrollar competencias prácticas en Administración de Sistemas Informáticos en Red mediante este laboratorio Virtual empresarial documentado y reproducible.
